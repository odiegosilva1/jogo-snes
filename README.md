 ## ARQUITETURA SNES

 - CPU RICO 5A22 - 3.58 Mhz (máximo)
 - MEMÓRIA RAM 128 KB
 - MEMÓRIA GRÁFICA OU PPU - PICTURE PROCESSING UNIT 2 X 64 - KB V RAM
 - CHIP DE SOM SPC 700
 - EMULADOR MOS 6502 Simulator (online)

 
 ## REGISTRADORES 8 OU 16 Bits

 A - ACCUMULATOR (OPEREÇẼOS LÓGICAS E ARTIMÉTICAS E GUARDAR VALORES)

 X/Y - INDEX REGISTERS (ACESSAR MEÓRIA PERCORRER LISTA DE DADOS E CONTROLAR LOOPS)
